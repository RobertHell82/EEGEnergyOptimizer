<objective>
Refactor the optimizer's `Decision` dataclass to expose three canonical fields — `reasons: list[str]`,
`blocked_by: list[str]`, `snapshot: dict` — populated by a closed snake_case catalog of reason keys
(D-09 to D-12). Replace `block_reasons` everywhere it is read, and migrate the activity-log
"Netzbezug abgebrochen" detection from a substring scan over `discharge_reasons` to a catalog-key
membership check on `blocked_by`. Change `_should_block_charging` to return
`(bool, list[str], list[str])` and `_should_discharge` to return
`(bool, float, list[str], list[str], bool)`. Add `Snapshot.to_telemetry_dict()` and
`EEGOptimizer._current_power_readings()` so `Decision.snapshot` carries the lean payload the
backend's `state_changes.snapshot_json` and `snapshots` tables consume directly.

Tests-first: every catalog key emitted by every branch in `_should_block_charging` /
`_should_discharge` is asserted; the closed-set invariant is enforced by `ALL_REASONS`.

Purpose: this is the foundation for plans 08-02 / 08-03. Until the Decision speaks the same
structured vocabulary the backend's `StateChangePayload` (see `EEGEnergyOptimzierBackend/src/types.ts`)
expects, no telemetry can be wired without re-doing this work later. By front-loading the rename +
signature change, the rest of the phase is purely additive.

Output: refactored `optimizer.py` (~+150 LOC for catalog/labels/helpers, ~−30 LOC for legacy
plumbing), migrated `sensor.py` (≈10 LOC), migrated `__init__.py` (≈3 LOC), updated tests.
</objective>

       ```python
       def _current_power_readings(self) -> dict:
           """Read live power values for the snapshot payload (D-09).

           Each value is float|None — None when the sensor is missing/unavailable (DO NOT

           cfg = self._config
           inv_type = cfg.get(CONF_INVERTER_TYPE, "")
           signs = INVERTER_SIGN_CONVENTIONS.get(inv_type, {})
           battery_sign = signs.get("battery_sign", 1)

           pv_raw = _read_power_kw(self._hass, cfg.get(CONF_PV_POWER_SENSOR, ""))
           grid_raw = _read_power_kw(self._hass, cfg.get(CONF_GRID_POWER_SENSOR, ""))
           bat_raw = _read_power_kw(self._hass, cfg.get(CONF_BATTERY_POWER_SENSOR, ""))
           cons_raw = _read_power_kw(self._hass, CONSUMPTION_SENSOR)

           return {
               "pv_now_kw": pv_raw,
               "grid_now_kw": (grid_raw * grid_sign) if grid_raw is not None else None,
               "battery_now_kw": (bat_raw * battery_sign) if bat_raw is not None else None,
               "consumption_now_kw": cons_raw,
           }
       ```
