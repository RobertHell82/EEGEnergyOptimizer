# Quick Task 260405-v06: SolarEdge StorEdge Inverter Support Summary

SolarEdge StorEdge battery control via solaredge-modbus-multi with command mode switching, NVRAM-safe stop, auto-detect, and wizard UI card.

## What Was Done

### Task 1: SolarEdgeInverter class (40c9cc2)
Created `inverter/solaredge.py` implementing `InverterBase` ABC with:
- **Charge blocking**: Sets storage_command_mode to "Maximize Export" (power_kw=0) or storage_charge_limit for partial limits
- **Forced discharge**: Sets backup_reserve first (pitfall 7), then discharge_limit, then "Discharge to Maximize Export" mode
- **Stop forcible**: Restores "Maximize Self Consumption" mode + original charge/discharge limits + original backup reserve
- **Original value storage**: Reads current limits and backup_reserve on init, prefers `max` attribute for charge/discharge limits
- **is_available**: Checks solaredge_modbus_multi config entries for loaded state

### Task 2: Factory, constants, manifest (5ee4367)
- Registered `SolarEdgeInverter` in `INVERTER_TYPES` factory dict as `"solaredge_storedge"`
