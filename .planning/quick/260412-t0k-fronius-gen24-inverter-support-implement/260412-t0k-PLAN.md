**1. Create `inverter/fronius.py` — FroniusInverter class:**

Follow the concept document (FRONIUS-GEN24-KONZEPT.md Section 6.1) precisely. Structure analogous to SolaXInverter but with direct Modbus TCP instead of HA entities.

```python
"""Fronius Gen24 inverter control via direct Modbus TCP (SunSpec Model 124).

Uses pymodbus AsyncModbusTcpClient for direct register writes.
Sensors are read via the native HA Fronius Integration (Solar API).
Only 2-3 registers written per operation: StorCtl_Mod, InWRte, OutWRte.

SunSpec Model 124 register offsets (relative to discovered base address):
  +0  WChaMax      uint16  R   Max battery power in W
  +3  StorCtl_Mod  bitfield16 RW  Control mode (Bit 0=Charge, Bit 1=Discharge)
  +5  MinRsvPct    uint16(SF-2) RW  Min reserve %
  +12 OutWRte      int16(SF-2)  RW  Discharge rate % of WChaMax
  +13 InWRte       int16(SF-2)  RW  Charge rate % of WChaMax
"""
```

Class structure:
- `__init__(self, hass, config)`: Call super(). Extract `fronius_modbus_host` and `fronius_modbus_port` (default 502) from config. Initialize `self._client = None` (lazy AsyncModbusTcpClient), `self._model124_base: int | None = None`, `self._wchamax: int | None = None`, `self._wchamax_date: str | None = None` (date string for daily cache), `self._slave_id = 1` (Fronius default Modbus unit ID).

- `async _ensure_connected(self) -> bool`: If `self._client` is None or not connected, create `AsyncModbusTcpClient(host, port=port)` and call `await self._client.connect()`. Return `self._client.connected`. Use try/except, log errors, return False on failure. Import pymodbus lazily inside method: `from pymodbus.client import AsyncModbusTcpClient`.

- `async _discover_model124(self) -> bool`: SunSpec Model Discovery per concept doc Section 6.1:
  1. Read registers 40000-40001, verify SunSpec ID (0x5375, 0x6E53 = "SunS")
  2. Start at address 40002, iterate: read 2 registers (model_id, length)
  3. If model_id == 124 -> store `self._model124_base = current_address`, return True
  4. If model_id == 0xFFFF -> end marker, return False
  5. Advance address by (length + 2), max 128 iterations
  Use `self._client.read_holding_registers(address, count, slave=self._slave_id)`. Log discovery progress at debug level. Log found base address at info level.

- `async _ensure_model124(self) -> bool`: If `self._model124_base` is None, call `_ensure_connected()` then `_discover_model124()`. Return whether base was found.

- `async _read_wchamax(self) -> int | None`: Read WChaMax (max battery power in W) from Model 124 offset +0. Cache for the current day (check `self._wchamax_date` against today's date string). If cached and same day, return cached value. Otherwise read register, cache, return value. Log the value at info level.

- `async _write_register(self, offset: int, value: int) -> bool`: Write a single register at `self._model124_base + offset`. Use `self._client.write_register(address, value, slave=self._slave_id)`. Increment `self.register_writes`. Add 200ms pause after write (`await asyncio.sleep(0.2)`). Return True on success, False on exception.

- `async async_set_charge_limit(self, power_kw: float) -> bool`:
  Per concept Section 6.1 "async_set_charge_limit":
  - Ensure model124 discovered and WChaMax read
  - If power_kw == 0 (block charging for Morgen-Einspeisung):
    - `StorCtl_Mod` (offset +3) = 1 (Bit 0: Charge Limit active)
    - `InWRte` (offset +13) = 0 (0% charge = no charging)
  - If power_kw > 0 (partial charge limit):
    - Calculate percent: `int(min(power_kw * 1000 / wchamax, 1.0) * 10000)`
    - `StorCtl_Mod` = 1
    - `InWRte` = percent
  - Return True on success, catch exceptions and return False

- `async async_set_discharge(self, power_kw: float, target_soc: float | None = None) -> bool`:
  Per concept Section 6.1 "async_set_discharge":
  - Ensure model124 discovered and WChaMax read
  - Calculate percent: `int(min(power_kw * 1000 / wchamax, 1.0) * 10000)`
  - `StorCtl_Mod` (offset +3) = 3 (Bits 0+1: Charge + Discharge Limit active)
  - `InWRte` (offset +13) = 0 (block charging during discharge)
  - `OutWRte` (offset +12) = percent
  - Optionally: if target_soc, set `MinRsvPct` (offset +5) = `int(target_soc * 100)` (SF -2)
  - Return True/False
  - **Add a TODO comment above this method:**
    ```python
    # TODO: KONZEPT open question 8.1 — StorCtl_Mod=3 may force grid discharge
    # even when house consumption could absorb battery output. Needs validation
    # on real Fronius Gen24 hardware. If confirmed, consider using StorCtl_Mod=2
    # (discharge-only) combined with separate charge blocking via a follow-up
    # StorCtl_Mod=1 write, or test if the inverter self-consumption logic still
    # applies under StorCtl_Mod=3.
    ```

- `async async_stop_forcible(self) -> bool`:
  Per concept Section 6.1 "async_stop_forcible":
  - `StorCtl_Mod` (offset +3) = 0 (no limits active)
  - `InWRte` (offset +13) = 10000 (100% charge allowed)
  - `OutWRte` (offset +12) = 10000 (100% discharge allowed)
  - Return True/False

- `@property is_available(self) -> bool`: Return `self._client is not None and self._client.connected`

- `async async_disconnect(self)`: If client connected, call `self._client.close()`. For cleanup.

**Error handling:** Every Modbus operation wrapped in try/except. On connection loss, set `self._client = None` so next operation reconnects. Log all failures with `_LOGGER.exception(...)`.

**Retry logic:** The `_ensure_connected` should attempt connection 3 times with 200ms delay between attempts if initial connect fails.

```python
# Check if Fronius native integration is loaded
fronius_entries = hass.config_entries.async_entries("fronius")
fronius_loaded = any(e.state.value == "loaded" for e in fronius_entries)

if fronius_loaded:
    # Detect Fronius sensors by suffix scanning
    sensors = {}
    for conf_key, suffixes in FRONIUS_SENSOR_SUFFIXES.items():
        for suffix in suffixes:
            for state in hass.states.async_all("sensor"):
                if (state.entity_id.endswith(suffix)
                        and state.state not in ("unavailable", "unknown")):
                    # Verify it's a Fronius entity by checking device info or naming
                    # Fronius entities typically contain "fronius" or "solarnet" or "power_flow"
                    eid = state.entity_id
                    if ("fronius" in eid or "solarnet" in eid
                            or "power_flow" in eid or "byd" in eid.lower()):
                        sensors[conf_key] = eid
                        break
            if conf_key in sensors:
                break

    result = {
        CONF_INVERTER_TYPE: INVERTER_TYPE_FRONIUS,
        "detected": True,
        "sensors": sensors,
    }
    connection.send_result(msg["id"], result)
    return
```
